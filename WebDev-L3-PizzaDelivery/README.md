# 🍕 PizzaHub - OIBSIP Level 3 | Pizza Delivery Full-Stack

**Live Demo:** https://jesimasherin240161.github.io/OIBSIP/WebDev-L3-PizzaDelivery/frontend/

## Tech Stack
Frontend: HTML, Tailwind CSS, JavaScript
Backend: Node.js, Express.js, JWT, Razorpay (Test Mode), Nodemailer, node-cron
Database: MongoDB

## Features
User: Register + Email Verify, Login JWT, Forgot Password, Custom Pizza Builder (Base 5 -> Sauce 5 -> Cheese -> Veggies), Order Summary, Razorpay Test Checkout, Real-time Tracking
Admin: Separate Login, Inventory Dashboard, Auto Decrement, Manual Stock Update, Low Stock Alert (<20) via node-cron, Order Management
